# Airport city data

`airport-cities.json` is generated by `scripts/generate-airport-cities.py` from
the `mborsetti/airportsdata` airport database:

- Source: https://github.com/mborsetti/airportsdata
- Snapshot commit: `4fce4daecf8df6be13a0c6f1568399cc617034a3`
- License: MIT
- Included rows: entries with a three-letter IATA code and a non-empty served city
- Stored shape: `{ "IATA": "city" }`

The table supplies the stable English served-city name used by the localization
generator. It is not used to invent or verify flight availability.

`public/map/airport-map-data.json` and `public/map/route-countries.geojson` are
generated by `scripts/generate-route-map-data.py`. Airport entries come from the
same pinned airportsdata snapshot and store
`{ "IATA": [latitude, longitude, ISO country] }`. Country boundaries come from
Natural Earth 1:110m at commit `ca96624a56bd078437bca8184e78163e5039ad19`.
Both files are used only by the route globe, never for availability or ranking.

The local globe textures in `public/map` are the Blue Marble and topology assets
bundled with `three-globe`. The product credits NASA Blue Marble next to the map;
no map tile service, runtime API key, or live location request is involved.

`airport-metro-groups.json` is generated by
`scripts/generate-airport-metro-groups.py` from airportsdata 20260315. It stores
the 41 IATA Multi Airport Cities and their member airports so the stopover
selector can show one city choice for airports such as HND and NRT.

`airport-localized-names.json` contains complete display names for the same 7,066
IATA entries in English, Simplified Chinese, Korean, and Japanese:

- Structured localized labels: Wikidata Query Service, CC0
- Missing-label fallback: Argos Translate offline models, MIT
- Chinese normalization: OpenCC `t2s`, Apache-2.0
- Product display overrides: a small set of reviewed metropolitan-area names
- Stored shape: `{ "IATA": { "en": "...", "zh": "...", "ko": "...", "ja": "..." } }`

Run `scripts/generate-airport-localizations.py` to rebuild the structured labels,
then install the `argostranslate` Python package and its models with
`scripts/install-airport-translation-models.py` and run
`scripts/fill-airport-localizations.py`. Install
`opencc-python-reimplemented` before filling the table. To normalize an existing
generated table without rerunning translation, use
`scripts/simplify-airport-localizations.py`. The generated table is read directly
at runtime. AI writes only the city-character description and cannot replace the
stored city name.
